# Shoe Store (React Hooks)

A React app for an online shoe store using the `useState` hook to manage the shopping cart.

## Features
- Shoes listed on the left with name, price and image
- Cart on the right showing name, price and quantity of each item
- "Add to Cart" button increases quantity (or adds the item)
- "Remove" button decreases quantity and removes the item at zero
- Cart total displayed at the bottom

## Run locally
```
npm install
npm run dev
```
